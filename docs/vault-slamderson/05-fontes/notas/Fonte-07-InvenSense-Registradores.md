# Fonte 07 — InvenSense: mapa de registradores

“MPU-6000 and MPU-6050 Register Map and Descriptions”, RM-MPU-6000A-00, revisão 4.0. A capa registra a data `03/09/2012`, preservada aqui no formato original. O arquivo de 47 páginas foi obtido da SparkFun; a autoria impressa é InvenSense.[7]

O documento organiza registradores de configuração, amostragem, filtros, medidas e identificação do dispositivo. É referência de programação do circuito integrado, não manual da placa adaptadora.[7]

## Uso no projeto

Consultar em conjunto com a especificação do componente. Registrar os valores efetivamente escritos no programa do ESP antes de converter medidas; não copiar faixas ou filtros apenas porque aparecem numa biblioteca.
